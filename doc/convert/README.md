# FPGA TF卡 BMP 图片批量转换工具

## 0. 图形界面 (`media_tool_gui.py`, 推荐)

把本目录下图片 / 音乐 / 字幕 / TF 卡同步几个脚本集中到一个窗口, 只需 Python 3 + Pillow (`pip install Pillow`).
启动: 双击 `media_tool_gui.bat`, 或 `python media_tool_gui.py`.

| 页面 | 功能 |
|------|------|
| 图片 | 添加图片或整个文件夹, 上移/下移调整播放顺序, 预览转换效果; **输出分辨率可选** (按宽高比分类的常用分辨率列表 84 个, 或直接输入任意 宽x高, 默认 640x400, 可横竖互换); 缩放方式可选 拉伸 / 等比裁剪铺满 / 等比补黑边; **每张图可单独设置分辨率 / 缩放方式 / 锐化 / 裁剪框 / 显示时长** (选中图片后勾选 “单独设置选中的图片”, 可多选; 不勾选时修改的是默认设置, 作用于其余图片; 列表中标 `[单独: ...]`, “全部恢复默认” 清除); 每次转换输出到新的子目录 `output_bmp/<宽x高>_<日期_时间>/` (如 `output_bmp/640x400_20261021_185932/`), 文件名带分辨率 `01_xxx_640x400.bmp`、`02_xxx_640x400.bmp`... (各图分辨率不同时子目录名为 `混合分辨率_<日期_时间>`), **不覆盖以前的结果** |
| 音乐 | 显示源 WAV 信息 (是否可直接播放); 可选采样率 (默认 48000)、单声道 (默认勾选)、只保留前 N 秒、音量倍数、峰值归一化; 显示输出大小与 TF 卡读取带宽; 可试听源文件与转换结果; 输出到 `output_wav/<原名>_<采样率>Hz_<单声道|立体声>.wav` (如 `song_48000Hz_单声道.wav`), 重名时加 `_2`、`_3`..., **不覆盖**, 写卡时改名为 `MUSIC.WAV` |
| 字幕 | 输入/打开文本, 选择中文字体、字号、笔画粗细; 实时统计字节数 (≤512)、汉字数 (≤64)、滚动一遍时长; 按 FPGA 实际字库渲染预览 (红线为一屏 640 像素) 及汉字 16x16 点阵放大图; 生成 `SUB.TXT` / `SUB.FNT` |
| 写入TF卡 | 自动列出可移动磁盘并显示卷标、文件系统、容量 (非 FAT32 或系统盘会红字警告); 默认取前三页**最近一次**的输出 (图片取最新的子目录, 音乐取最新的 WAV; 可点“浏览...”换成以前的结果), **播放列表**可上移 / 下移调整播放顺序, 给选中或全部图片设置显示秒数 (默认沿用图片页每张图设置的时长); 默认**按文件夹分类写入** `IMG\IMG01~16.BMP`、`MUSIC\MUSIC.WAV`、`SUB\SUB.TXT / SUB.FNT`, 并在根目录生成播放列表 `PLAY.CFG` (每行 `编号 秒数`, 可用记事本直接改顺序和秒数; 取消勾选则按旧版全部放根目录); 逐个检查格式, 确认后清空根目录再写入 |

各页的输出路径会自动带到 “写入TF卡” 页, 一般按 图片 → 音乐 → 字幕 → 写入TF卡 的顺序操作一遍即可.
下文的命令行脚本仍可单独使用.

这个脚本（`convert_images_to_bmp.py`）专为本 FPGA 工程设计，主要用于将用户手中的各种常见图片格式快速转换为满足本系统 TF 卡读取要求的标准格式：**640x400 分辨率、24 位、无压缩的 BMP 图片**。

> **为什么是 640x400**：FPGA 以 1280x800 (16:10) 输出 HDMI, 画面按 640x400 合成后每个像素 2x2 放大.
> 1920x1200 等 16:10 显示器会把 1280x800 等比放大 1.5 倍铺满全屏, **没有黑边、不变形**.
> **其他分辨率的 BMP 也可以直接放进 TF 卡** (宽高 16~4096, 24/32 bit 非压缩, 自下而上或自上而下存储均可):
> FPGA 加载时等比缩放 (最近邻) 到 640x400, 比例不同时上下或左右补黑边居中, 不变形.
> 预先转换的好处: 用 LANCZOS 高质量缩放, 文件只有 750 KB, 加载最快 (1920x1080 原图约 6 MB, 读卡时间约为 8 倍);
> 想铺满不留黑边时用 `--fit crop`.

## 1. 支持的输入图片格式

脚本内部依赖 Python 的 `Pillow` (PIL) 库进行图像解析，因此它支持绝大多数主流图像格式的读取，包括但不限于：
- `.jpg` / `.jpeg`
- `.png`
- `.bmp` (对现有 BMP 调整大小或重设色深)
- `.webp`
- `.gif` (提取第一帧)

*注：无论输入图片本身是否带有透明通道（Alpha），转换时均会统一转换为纯 RGB（24 位）模式并去除透明通道信息，以防止 FPGA 端读取到不支持的 32 位图片。*

## 2. 核心功能

1. **自动调整分辨率**：统一使用高质量的 `LANCZOS` 采样算法将图片缩放至严格的 `640x400` 大小。
2. **格式标准化**：将图片强制存为无压缩的 Windows Bitmap (BMP) 格式，色深固定为 24 位（8-bit Red, 8-bit Green, 8-bit Blue）。
3. **双重运行模式**：支持一键式批量转换文件夹，也支持命令行精确指定单文件转换。

## 3. 环境准备

运行此脚本需要电脑上安装有 Python 3 及 `Pillow` 库。
你可以通过以下命令快速安装依赖：
```bash
pip install Pillow
```

## 4. 使用方法

### 模式一：批量转换（推荐）
如果你有很多图片需要一次性转换：

1. 双击运行 `convert_images_to_bmp.py`，或在终端中执行：
   ```bash
   python convert_images_to_bmp.py
   ```
2. **首次运行**时，由于没有图片，脚本会在同级目录下自动创建一个名为 `input_images` 的文件夹。
3. 把你需要转换的所有图片（支持混合格式）复制到 `input_images` 文件夹中。
4. **再次运行**脚本，转换成功后，脚本会自动生成一个 `output_bmp` 文件夹。
5. 将 `output_bmp` 文件夹里新生成的 `.bmp` 图片全部拷贝到你的 TF 卡根目录下即可。

### 模式二：命令行单文件精准转换
如果你只想转换一张图片，并指定输入/输出路径，可以在终端或命令行（cmd/powershell）中使用如下格式：
```bash
python convert_images_to_bmp.py <输入文件> <输出文件>
```

### 输出分辨率 `--size`
默认 640x400. 用 `--size 宽x高` 指定任意分辨率 (宽高 16~8192), 单张和批量都适用, 裁剪框比例自动跟随:
```bash
python convert_images_to_bmp.py 照片.jpg out.bmp --size 1920x1080
python convert_images_to_bmp.py --size 1080x2400 --edit       # 批量, 竖屏, 逐张自定义裁剪
python convert_images_to_bmp.py --list-sizes                  # 列出常用分辨率 (16:10 / 16:9 / 4:3 / 5:4 / 3:2 / 21:9 / 32:9 /
                                                              #   小屏 / 电视 / 手机竖屏 / 平板 / 正方形)
```
图形工具中在 “输出分辨率” 处先选分类再选分辨率, 也可直接输入后回车; 裁剪窗口的右侧预览在放得下时 1:1 显示, 大分辨率自动等比缩小显示.

### 缩放方式 `--fit`
两种模式都可加 `--fit` 选择非 16:10 图片的处理方式 (手机照片会先按 EXIF 方向旋正, 透明区域填黑):

| 取值 | 效果 |
|------|------|
| `crop` (默认) | 保持比例放大, 居中裁掉多余部分, 铺满画面 |
| `stretch` | 直接拉伸到 640x400, 可能变形 |
| `pad` | 保持比例缩小, 完整显示, 四周补黑边 |

```bash
python convert_images_to_bmp.py 手机照片.jpg 1.bmp            # 默认 crop, 铺满无黑边
python convert_images_to_bmp.py 手机照片.jpg 1.bmp --fit pad  # 完整显示, 补黑边
```

### 自定义裁剪框与预览 `--edit` / `--crop`
默认 crop 裁掉的是上下 (或左右) 两边各一半; 想保留人脸、文字等偏在一边的内容, 或者只截取局部放大时, 可以自己选裁剪框:

```bash
python convert_images_to_bmp.py 手机照片.jpg 1.bmp --edit     # 打开裁剪窗口, 确定后转换
python convert_images_to_bmp.py --edit                         # 批量: input_images 中的图片逐张打开
python convert_images_to_bmp.py 手机照片.jpg 1.bmp --crop 0.5,0.3,1.5   # 不开窗口, 直接用参数
```

- 窗口左边是原图, 黄框为 16:10 裁剪框 (框外变暗, 虚线为三分线): 左键拖动, 框外单击把框移过去, 滚轮或 `+`/`-` 缩放, 方向键微调 (Shift 加快);
  另有 居中 / 靠上 / 靠下 / 靠左 / 靠右 / 整幅 按钮.
- 右边按 **1:1 像素** 实时显示转换结果, 即 FPGA 合成的 640x400 画面; 下方显示 “每个输出像素对应几个源像素”, 小于 1 时提示放大会发糊.
- `--crop CX,CY,ZOOM`: 框中心相对原图宽 / 高的位置 (0~1) 与放大倍数 (1 = 能放下的最大框, 最大 8). 单文件 `--edit` 确定后会打印对应的参数, 下次可直接复用.
- 批量 `--edit` 的结果存入 `input_images/crop_settings.json`, 以后不加 `--edit` 批量转换也按保存的裁剪框处理; 窗口中取消 = 停止转换后面的图片.
- 图形工具 `media_tool_gui.py` 的 “图片” 页同样有 “自定义裁剪框...” 按钮 (或双击列表中的图片), 设置裁剪框后该图自动变为单独设置 (列表中标 `[单独: ... · 自定义裁剪框]`), “恢复居中” 取消裁剪框.

### 锐化 `--sharpen`
640x400 的画面在 1920x1200 显示器上相当于放大 3 倍, 缩小后适当锐化 (USM, 半径 1 像素) 边缘和文字会更清楚.
默认 `--sharpen 50`, 范围 0~150, `0` 为不锐化 (与旧版输出相同); 裁剪窗口和图形工具中可用滑块边看边调.

> 想要最清楚的效果: 用电脑预先转换 (LANCZOS 高质量缩小 + 锐化), 不要把大照片直接放进 TF 卡让 FPGA 缩放 (板上是最近邻, 细节会发毛).

## 5. TF 卡一键同步 (`sync_to_sd.py`)

新版 FPGA 工程 (`sd_media_loader`) 通过 **FAT32 文件系统** 读取根目录文件, 不再做物理扇区扫描,
因此不会再误读已删除的残留图片, 也无需破坏旧文件头. 脚本功能:

1. 清空 TF 卡根目录 (保留 `System Volume Information`), 使用 `--keep` 可跳过;
2. 把源目录中的 BMP 按文件名排序, 依次复制为 `IMG01.BMP` ~ `IMG16.BMP`
   (最多 16 张, OSD 信息栏显示文件名前 8 个字符). 会检查 BMP 文件头: 宽高 16~4096、24 bit 非压缩或 32 bit、
   文件大小足够 (含每行补齐到 4 字节), 不符合的跳过并提示;
3. 可选复制背景音乐 `MUSIC.WAV`、字幕 `SUB.TXT` 与字库 `SUB.FNT`.

```bash
python sync_to_sd.py E:
python sync_to_sd.py E: -s my_bmp -w MUSIC.WAV -t SUB.TXT -f SUB.FNT
python sync_to_sd.py E: -n 4 --keep
```

TF 卡根目录约定 (FPGA 按目录顺序识别):

| 文件 | 要求 | 用途 |
|------|------|------|
| `*.BMP` | 任意分辨率 16~4096, 24/32 bit, 最多 16 张 (FPGA 等比缩放到 640x400, 补黑边居中) | 图片 (按键切换 / 自动轮播) |
| 第一个 `*.WAV` | PCM 8/16 bit, 单/双声道, 8k~48kHz | 背景音乐, 经 HDMI 输出, 播完循环 |
| 第一个 `*.TXT` | 前 512 字节 | OSD 滚动字幕 |
| 第一个 `*.FNT` | 2048 字节 | 字幕用户字库 (中文) |

TF 卡需格式化为 **FAT32** (32GB 以下默认即是).

## 6. 背景音乐转换 (`convert_wav.py`)

把任意 WAV (8/16/24/32 bit 整数、float32/64、WAVE_EXTENSIBLE) 转成播放器支持的 16 bit PCM WAV.
默认一律重采样到 **48000 Hz** (与第十一讲 `make_audio_corpus.py` 相同): 电脑端用 Kaiser 窗 sinc 滤波 (装有 numpy 时; 否则线性插值),
FPGA 端 48k 样本与 HDMI 48k 输出帧一一对应, 不经硬件插值, 音调音质与原曲一致. 推荐再加 `--mono` (96 KB/s, 不易欠载断音).
装有 ffmpeg 时也可以直接输入 mp3/flac 等格式.

```bash
python convert_wav.py song.wav --mono             # -> MUSIC.WAV, 48000 Hz 单声道 (推荐)
python convert_wav.py song.mp3 -o E:/MUSIC.WAV --mono --seconds 60
```

| 参数 | 说明 |
|------|------|
| `-o` | 输出文件 (默认 MUSIC.WAV) |
| `--rate` | 目标采样率 (默认 48000) |
| `--keep-rate` | 原采样率在 8k~48k 内时保持不变, 由 FPGA 线性插值到 48k (文件更小, 高音略有损失) |
| `--force-rate` | 强制重采样到指定采样率 (同 `--rate`) |
| `--mono` | 混成单声道 (TF 卡带宽减半, 推荐) |
| `--seconds` | 只保留前 N 秒 |
| `--gain` | 音量倍数 (过大导致削波时会提示) |
| `--normalize` | 把峰值归一化到 98% 后再乘 `--gain`, 适合原声太小的录音 |

## 7. 滚动字幕生成 (`make_subtitle.py`)

把 UTF-8 文本 (可含中文) 转成 `SUB.TXT` + `SUB.FNT`. ASCII 字符用 FPGA 内置字库,
每个汉字用 Windows 字体渲染成 16x16 点阵, 拆成左右两个 8x16 字模 (占两个码 0x80+2k / 0x80+2k+1),
最多 64 个不同汉字, 字幕总长 512 字节.

```bash
python make_subtitle.py "欢迎使用安路 FPGA 多媒体播放器!" --preview
python make_subtitle.py -f 字幕.txt -o E:/
python make_subtitle.py "..." --font C:/Windows/Fonts/simhei.ttf --threshold 100
```

纯 ASCII 字幕只生成 `SUB.TXT`, 不需要 `SUB.FNT`.
